# Lynko project
What is link? an personal linktree generator with custom styles, layouts, native responsivness & downloadable, click create download and host in any place!
made with nextjs lucide icons, icons 8 icons, typescript, and modern clean stacks like bun on background!

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
